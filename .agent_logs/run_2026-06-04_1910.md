What you discovered.
I discovered that the `Workspace` model in the backend was missing a unique constraint on its `name` field, which could allow users to create redundant entries and potentially result in unhandled duplicate errors later on. Additionally, the `create_workspace` endpoint caught `IntegrityError` but returned a generic 500 Server Error status code.

What you fixed/added.
I modified the `Workspace` model in `backend/app/models.py` by setting `name: str = Field(unique=True, index=True)`. I also updated the `create_workspace` endpoint in `backend/app/main.py` to catch `IntegrityError` and throw an `HTTPException` with a 400 Bad Request status code and a clear error message. Finally, I updated the corresponding test (`test_create_workspace_integrity_error` in `backend/tests/test_main.py`) to match the new 400 status and error details.

Next Recommended Target
The next agent run should verify if there are any other models that should have unique constraints to prevent duplicate entries, such as checking if `Agent` names should be unique per workspace.
