What you discovered.
I discovered that several backend files in the FastAPI application (`backend/app/auth.py`, `backend/app/encryption.py`, `backend/app/database.py`, and `backend/app/main.py`) were missing proper Python type hints. This made the code harder to read, maintain, and prone to typing errors in the future.

What you fixed/added.
I added missing type hints to functions across the backend application:
- `backend/app/auth.py`: Added `str` and `bool` parameter/return types to `verify_password`, `get_password_hash`, and `create_access_token`.
- `backend/app/encryption.py`: Added `bytes` return type to `get_encryption_key`.
- `backend/app/database.py`: Added `None` and `Generator[Session, None, None]` return types to database setup functions.
- `backend/app/main.py`: Added `dict[str, str]`, `None`, and `list` types to various FastAPI route handlers and Socket.IO event handlers. Also added parameter type hints to socket handlers (`sid: str`, `data: dict`, `environ: dict`).
