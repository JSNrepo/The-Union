What you discovered.
While inspecting the `backend/app/main.py` code, I discovered that several nested and un-hinted functions lack proper type hints, specifically `lifespan`, `fetch_agent_infos`, `handle_agent`, and `fetch_agent_data`. This makes it harder for type checkers (like Pyright) and other developers to understand the return types and arguments of these asynchronous and background functions.

What you fixed/added.
- Imported `AsyncIterator` and `Any` from `typing` in `backend/app/main.py`.
- Added the `-> AsyncIterator[None]` return type hint to the `lifespan` function.
- Added the `-> list[dict[str, Any]]` return type hint to the `fetch_agent_infos` function.
- Added the `agent_info: dict[str, Any]` argument hint and `-> None` return type hint to the `handle_agent` function.
- Added the `-> dict[str, Any]` return type hint to the `fetch_agent_data` function.
