## What you discovered

In `backend/app/main.py`, I identified that the socket.io event handlers (`join_workspace` and `chat_message`) had early return paths for input validation to prevent unhandled exceptions and DoS. However, these specific validation paths were not covered by any tests in the test suite.

## What you fixed/added

Added three new test cases to `backend/tests/test_socket.py`:
1. `test_join_workspace_invalid()`: Tests that invalid input (non-dict data, missing `workspace_id`, excessively long `workspace_id`) properly exits without joining the workspace.
2. `test_chat_message_invalid_data()`: Tests that invalid inputs for chat messages do not get emitted.
3. `test_chat_message_mention_without_valid_agents()`: Tests that mentioning something that doesn't resolve to a valid agent (e.g. `@ everyone`) won't trigger the API proxy process but will still be correctly processed as a regular chat message.

This improves the test coverage on the critical real-time application paths.
