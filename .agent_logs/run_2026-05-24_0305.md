What you discovered:
During the scout phase, I analyzed the backend test coverage by running pytest with the `--cov=app --cov-report=term-missing` flags. The report showed that `app/encryption.py` was lacking test coverage for specific edge cases: missing `UNION_MASTER_KEY` environment variable (line 10) and hardware salt exceptions during fallback generation (lines 15-16).

What you fixed/added:
I added two new unit tests in `backend/tests/test_encryption.py` to cover these missing lines:
1. `test_get_encryption_key_missing_master_key`: Tests that a missing `UNION_MASTER_KEY` correctly raises a `RuntimeError` by mocking `os.environ`.
2. `test_get_encryption_key_fallback_salt`: Tests that the fallback salt is correctly used when `uuid.getnode()` raises an Exception by mocking both `uuid.getnode` and `os.environ`.

Next Recommended Target:
Increase test coverage in `app/main.py`. The coverage report indicated missing lines at 55, 157, and 279, which correspond to server configuration errors, edge cases where no agents are found in a message mention, and authorization checks.
