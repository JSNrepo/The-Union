Phase 1: Scout
What I discovered:
I discovered an issue in the frontend tests where `simulates receiving a chat_update message` fails. The issue was that the `act` function wasn't handling the promise resolution correctly to allow React to flush effects (like auto-scrolling) triggered by state updates. The test needed an `await act(async () => { await new Promise((r) => setTimeout(r, 0)); });` block.

Phase 2: Execute
What I fixed/added:
- I fixed the `chat_update` message test in `frontend/src/app/page.test.tsx` by wrapping the promise resolution in an `act` block so that React can properly process the state update before checking the DOM.
