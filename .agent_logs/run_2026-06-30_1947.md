**Discovery:**
The "Send" button in the chat interface relied on the native `title` attribute for its tooltip, and the "Copy message" button lacked an explicit screen reader announcement for its transient success state ("Copied!").
**Fix:**
Replaced the native `title` tooltip on the "Send" button with a custom accessible tooltip implementation using `role="tooltip"`, `aria-hidden="true"`, and appropriate CSS focus/hover states (`peer-focus-visible:opacity-100 group-hover/send:opacity-100`). Also, added an `aria-live="polite"` sr-only div to the "Copy message" component to ensure the transient success state is announced to screen reader users.
**Next Recommended Target:**
Audit the application for other interactive elements that might rely solely on native `title` attributes and replace them with custom accessible tooltips to ensure consistent styling and discoverability for keyboard users.
