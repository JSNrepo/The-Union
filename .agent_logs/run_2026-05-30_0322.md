## What you discovered
In `backend/app/main.py`, the `sync_token` function used `x_api_key: str = Header(None)`. Since the default value is `None`, the type hint should have explicitly allowed `None` using the union operator (`str | None`), and `Header(None)` should be updated to `Header(default=None)` to comply with current FastAPI best practices and prevent type checking errors with Pyright.
