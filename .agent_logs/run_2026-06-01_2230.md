# Autonomous Run Log

## What you discovered
- I discovered that `database.py` had `echo=True` set directly inside `create_engine()`. This configuration forces SQLAlchemy to write every executed SQL statement to standard output (`stdout`) synchronously.
- In a production ASGI environment using threadpools for synchronous routes, this triggers synchronous file I/O operations that block thread execution, causing significant latency and degrading API and WebSocket concurrency under load.

## What you fixed/added
- Disabled synchronous SQL logging by modifying `database.py` to set `echo=False` in `create_engine()`.
- Added a comment indicating this is a Bolt optimization to prevent regression.
- Updated `.jules/bolt.md` with a journal entry recording this performance learning.
