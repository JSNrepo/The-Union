What I discovered:
I discovered that `pyright` fails on `backend/app/main.py` with the error `Operator "|" not supported for types "bool" and "BooleanClauseList"` on line 223. This is because Pyright correctly identifies that SQLAlchemy implicit comparisons using pure class attributes without `col()` (like `Agent.workspace_id == ws_uuid`) return a plain `bool` from Pyright's perspective instead of a SQLModel `BooleanClauseList`, causing bitwise operations (`|`) to fail type checking.

What I fixed/added:
I explicitly wrapped `Agent.workspace_id` and `Agent.owner_id` with SQLModel's `col()` wrapper on line 223 to generate correct `BooleanClauseList` types for the SQLAlchemy query condition (`(col(Agent.workspace_id) == ws_uuid) | ((col(Agent.workspace_id).is_(None)) & (col(Agent.owner_id) == uuid.UUID(session_data.get('user_id'))))`). This satisfies Pyright's strict type checking.
