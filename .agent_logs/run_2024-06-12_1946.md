# Autonomous UX Improvement Log
Date: 2024-06-12 19:46

## What you discovered
While navigating the SPA, I noticed that the browser tab title remains static ("The Union | AI Workspace") regardless of the selected workspace. This lack of dynamic context can be confusing for users with multiple tabs open and diminishes the experience for screen reader users who rely on the document title to understand their current context when switching windows.

## What you fixed/added
- Added a new `useEffect` hook in `frontend/src/app/page.tsx` that listens to changes in `activeWorkspace`.
- The hook dynamically updates `document.title` to `${activeWorkspace.name} | The Union` when a workspace is selected.
- Updated `README.md` to document this enhancement with screenshots.

## Next Recommended Target
- Implement unread message indicators or read receipts to provide better visual cues for incoming messages when a workspace is not actively focused.
