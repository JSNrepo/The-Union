However, this `except` block (lines 225-227) lacked test coverage, leaving the application vulnerable to regressions in race condition handling.

Added a new test case `test_register_integrity_error` in `backend/tests/test_main.py` to cover the `except IntegrityError` block. The test mocks `sqlmodel.Session.commit` to side-effect `IntegrityError` and asserts that the proper 400 Bad Request response is returned. The coverage of `backend/app/main.py` is now 100%.
