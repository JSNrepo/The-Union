What you discovered:
During my scan of the repository for missing type hints, I ran Pyright on the backend code (`pyright backend/app/`) and discovered three type errors in `backend/app/main.py`. The `.join()` method calls on SQLModel select statements (at lines 64, 168, and 259) were using boolean conditions (e.g., `Agent.id == TokenPool.agent_id`) as the `onclause`, which Pyright correctly flagged as invalid type assignments (Argument of type "bool" cannot be assigned to parameter "onclause" of type "_OnClauseArgument | None" in function "join").

What you fixed/added:
I fixed the Pyright type errors by replacing explicit `onclause` parameters (`Agent.id == TokenPool.agent_id`) with a simplified `.join(TokenPool, isouter=True)`. SQLAlchemy and SQLModel can automatically infer the join condition from the foreign key relationship defined on `TokenPool.agent_id`. This correctly resolves the typing issue and preserves the same query structure. I also verified the test suite runs correctly with no regressions.
