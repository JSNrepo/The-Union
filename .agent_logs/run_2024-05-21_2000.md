## What you discovered
- The main chat input didn't have a quick keyboard shortcut to focus it, forcing users to click every time they want to start typing in the workspace.
- Adding a simple `/` keyboard shortcut is a standard and highly effective UX pattern for this type of application.
- I noticed that `.jules/palette.md` had previous learnings, so I correctly appended my new learning about keyboard shortcut discoverability (using `<kbd>` cues) instead of overwriting the file.
