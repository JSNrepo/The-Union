What you discovered.
The codebase lacked basic test coverage for the backend `app.auth` and `app.encryption` modules. These are critical components responsible for handling password hashing, JSON Web Tokens (JWT) creation, and symmetric encryption of sensitive AI tokens. Without tests, any future changes or refactors could silently break security features.

What you fixed/added.
- Set up the test suite by creating the `backend/tests/` directory and adding a `conftest.py` file to automatically inject required environment variables (`SECRET_KEY`, `UNION_MASTER_KEY`, etc.) before any tests are run.
- Wrote `test_auth.py` to cover password hashing functionality (`get_password_hash` and `verify_password`) and JWT access token creation.
- Wrote `test_encryption.py` to verify that the core encryption utility methods (`encrypt_token` and `decrypt_token`) function symmetrically, returning the original string when decrypted.
