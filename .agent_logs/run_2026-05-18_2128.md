What you discovered:
I discovered an unhandled recursion error (unhandled error) in the backend's ASGI application mounting. Specifically, in `backend/app/main.py`, the `socket_app` was instantiated with `other_asgi_app=app`, but was then mounted recursively onto `app` using `app.mount("/", socket_app)`. This resulted in an infinite loop and `RecursionError` for any requests targeting undefined routes (e.g. 404 paths) or during high load concurrency, bringing down the Uvicorn worker.

What you fixed/added:
I corrected the mounting mechanism by making the paths non-overlapping. `socket_app` now handles only the Socket.IO routes (`socketio_path=""`) and is explicitly mounted to `/socket.io` via `app.mount("/socket.io", socket_app)` without setting `other_asgi_app=app`. This completely resolved the recursive loop while still cleanly supporting FastAPI endpoints and WebSocket connections in the same application. I verified the change locally using a crash script and pytest tests.
