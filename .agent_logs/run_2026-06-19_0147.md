I added two new test functions in `tests/test_main.py`: `test_register_cleanup` and `test_login_cleanup`. These tests mock `time.time()` to simulate time passing and explicitly trigger the cleanup condition by adding old attempts and verifying that they are successfully removed from the global dictionaries. The backend test coverage is now at 100%.
