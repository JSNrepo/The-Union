I added a new test `test_sync_token_update_existing` to `backend/tests/test_main.py`. This test correctly mimics the extension behavior: it first creates an initial token via `/sync-token`, and then triggers a secondary request with the same `agent_id` to ensure the existing `TokenPool` row is properly updated with the new token instead of causing an error or duplicating entries.
