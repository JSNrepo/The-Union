## What I discovered
While scanning the codebase for isolated issues, I found missing test coverage in `backend/app/main.py`. Specifically, the `join_workspace` WebSocket event handler lacked a test case for when a user fails authorization via `verify_ws_auth_sync`. If `verify_ws_auth_sync` returns `None`, the handler exits early, but this return path was entirely untested in the existing test suite (`backend/tests/test_socket.py`).

## What I fixed/added
I added a new test `test_join_workspace_unauthorized` in `backend/tests/test_socket.py`. This test mocks `verify_ws_auth_sync` to return `None` and asserts that neither `enter_room` nor `emit` are called, ensuring the early return logic is properly covered and tested.

## Next Recommended Target
I recommend looking into the missing coverage for other endpoints and error states in `backend/app/main.py`, particularly around token synchronization (`sync_token`) and basic auth error handling, which still have significant untested lines.
